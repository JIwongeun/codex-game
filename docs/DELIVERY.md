## 2. 성공 정의

제출 준비 완료는 다음을 모두 만족하는 상태다.

- 공개 HTTPS URL을 시크릿 창에서 열 수 있다.
- 한 번의 클릭으로 시작하고 피격까지 생존 시간을 기록할 수 있다.
- 마우스 이동, 공격 예고, 피격, 종료, 즉시 재시작이 동작한다.
- 첫 방문자가 계정과 이름 입력 없이 익명으로 바로 플레이한다.
- 실제 제3자 로고나 권리 불명 에셋이 없다.
- `pnpm check`가 통과한다.
- 16:9 썸네일이 있다.
- 3분 이하 실제 플레이 영상 링크가 있다.
- Codex 활용 과정이 사실에 맞게 정리되어 있다.

## 4. 기능 우선순위와 컷 기준

### 반드시 유지

- 이동
- 생존 시간
- 한 번 피격 종료와 즉시 재시작
- 직선 공격과 예고형 범위 공격
- 시간 기반 난이도 상승
- 공개 웹 빌드

### 시간이 부족하면 단순화

- 공격 4종 → 직선 공격 2종
- 범위 공격 2종 → 원형 범위 1종
- 음악 → 효과음만

### 가장 먼저 제거

- 글로벌 랭킹, 게스트 ID, 랭킹 서버
- 특수 아이템
- 일일 시드와 기간별 랭킹
- 모바일 터치 최적화
- 추가 게임 모드
